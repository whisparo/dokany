📐 الميثاق المعماري النهائي والمغلق (The Master Blueprint)
🎨 المبادئ المعمارية الحاكمة (The Architectural Pillars)
Clean Overlay Pattern (Zero-Bloat Storefront):

طبقة التحرير (store-editor) مفصولة تماماً عن شجرة مكونات الزبون (Storefront).

يتم تحميل كود التحرير بـ Dynamic Import (ssr: false) للتاجر فقط بناءً على فحص الملكية والجلسة عند وجود المعلمة ?edit=1.

Edge-Cache Proof Auth Anchor (سلامة الكاش والأمان):

صفحات الـ Storefront تُخزن على الـ Edge Cache (مثل Cloudflare CDN) بسياسات التخزين s-maxage=3600.

الضمانة: كود المحرر والزر التفاعلي غير موجودين مطلقاً في الـ HTML المولد سيرفرالياً أو المخبأ في الكاش. المعلمة ?edit=1 تُفحص حصراً لدى متصفح العميل (Client-Side) بعد التحقق التام من الـ Session والـ Ownership، مما يمنع تسريب المحرر أو إضعاف أداء الـ CDN للزبائن.

Feature-Driven Isolation:

كل ميزة عبارة عن صندوق مغلق (Self-Contained Module) يملك الـ UI, Hooks, State, Actions, و Types الخاصة به.

Optimistic UI & Progressive Media Enrichment (Zero-Cost Optimization):

إضافة سريعة فورية: التاجر يرفع الأصل ويحصل فوراً على استجابة سريعة في الـ UI بوضع status = 'raw' عبر Cloudinary.

معالجة خلفية: يقوم الـ Pipeline بتنقية الصور وإزالة الخلفيات (إذا كانت media_type = 'image') وأرشفتها في Backblaze B2 asynchronously وتحويل الحالة إلى status = 'processed'.

توحيد العرض: الهيرو والمنتجات تستخدم نفس المحرك الموحد: العرض من B2 عند الجاهزية والـ Fallback على Cloudinary لحين الانتهاء لتوفير التكلفة نهائياً.

Multi-Tenant Isolation (Product Slugs & Variants SKUs):

عزل تام على مستوى المتاجر بفرادة مرّكبة UNIQUE(store_id, slug) للمنتجات لمنع تصادم روابط الـ SEO، و UNIQUE(store_id, sku) للـ Variants لمنع التعارض مع الحفاظ على الـ Transactions الذرية.

Unified Financial Precision Standard:

توحيد كافة الأسعار والمبالغ في كافة الجداول (products و product_variants) كـ INTEGER بأصغر وحدة عملة (فلس / سنت / هللة) للحد التام من أخطاء التقريب بكسور النقطة العائمة (Floating Point Imprecision) عند الفواتير والخصومات.
